# Agent Note: 不重新激活会话的归档恢复

Status: implemented

[English](2026-10-21-archived-session-recovery.md) | 中文

## 问题

已归档会话保留日志及工作空间记账，但隐藏的会话需要可发现的恢复操作。为浏览归档而打开会话会读取历史，还可能激活智能体。较晚返回的归档响应也可能覆盖另一页面发出的较新成员集合帧。

## 决策

工作空间注册表在既有串行写入队列上持有 `restoreSession`。恢复仅移除归档成员资格，保留日志、工作空间记账及手动顺序。对已恢复的已知会话重复操作不再写入；明确缺失的会话被拒绝，存储查询失败原样传播。恢复既不选择会话，也不启动执行。既有域版本和存储字段足够表达恢复。

Host API 返回完整已提交归档集合，并广播既有归档变化帧。客户端串行提交自身的归档／恢复写入；若另一完整 Host 观察已取代一元成员回声，则忽略该旧回声。写入失败保留上次已知成员集合，失败请求不妨碍之后重试。基线加载期间到达的帧或有效回声仍优先于基线携带的旧归档集合。

工作空间 UI 通过既有会话及工作空间数据源持有独立归档页。元数据筛选不读取会话正文。会话元数据缺失时仍显示标识，不把缺失元数据呈现为空归档。部署已配置的搜索结果上限约束渲染前缀，并提示缩小筛选。断线或基线不可用时禁用恢复。恢复成功使原行按钮移除后，键盘焦点转向状态信息。筛选控件在页面重新挂载时保留；浏览器重新加载后从 Host 重建成员集合。

[全局归档决策](2026-07-31-session-archive-global-set.zh.md) 继续持有归档存储及过滤职责。[工作空间侧边栏顺序](2026-08-11-workspace-sidebar-order-and-folding.zh.md) 继续持有独立的浏览器展示偏好；恢复不改写这些偏好或持久记账。

## 已考虑的替代方案

**打开每条已归档会话以建立条目。** 归档成员资格及元数据无需历史读取和智能体激活。

**重新附加会话来恢复。** 附加可能改变位置，也会混淆记账成员资格与归档可见性。

**相信最后到达的一元响应。** 到达顺序不能确定跨页面提交顺序；旧响应可能抹去较新的完整集合帧。

## 后果

无需加载内容即可发现已归档会话。缺失会话元数据仍可见，但元数据本身不能证明日志可读。恢复保留数据和选择，不作为运行重试操作。项目产物目录仍是独立能力。

## 验证

注册表测试覆盖持久恢复、重复无写入、未知标识、存储查询失败、串行操作及重启后记账不变。传输及运行时测试覆盖完整集合 RPC、帧、失败保留及延迟响应优先级。组件测试覆盖筛选、上限、元数据缺失、卸载、控件保留及完成焦点。真实组合浏览器场景覆盖多条归档会话、另一已连接页面、重连、中文控件、明暗主题及窄屏，且不增加模型请求。
