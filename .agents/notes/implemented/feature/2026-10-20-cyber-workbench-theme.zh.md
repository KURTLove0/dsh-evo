# Agent Note: 赛博工作台主题

Status: implemented

[English](2026-10-20-cyber-workbench-theme.md) | 中文

## Problem

赛博科技界面需要在独立加载的 UI 插件之间统一背景层次与操作强调。组件各自维护深色配色，会在切换主题和插件重载时产生差异。

## Decision

主题插件拥有冰蓝和深海蓝静态色板、青色语义强调、焦点光晕、图案底板、阴影与共享圆角。现有主题偏好和插件组合仍是权威来源。功能 CSS 使用这些变量，不选择主题，也不下载字体。

静态网格仅属于空会话画布。活跃对话使用纯色背景，确保代码、工具输出和长回复易于阅读。控件保留清晰的键盘焦点、粗精度指针操作区域与减少动态效果行为。深色应用图案使用浅色底板，不随主题替换图片。

[样式系统记录](../process/2026-07-19-web-styling-system.zh.md)继续拥有 CSS Modules、仅使用 token 颜色和组件隔离规则。本决策改变其中工作台界面与 Chat 对齐的视觉基线；其工程约束继续有效。

模块导航使用独立有界滚动区域，避免可选入口在较矮窗口中挤占会话浏览器。键盘聚焦会显示屏幕外入口；会话行保留自己的滚动条占位。

## Consequences

共享基础控件与插件页面通过语义别名同步变化。第三方主题覆盖需要验证新增视觉 token 及其自身对比度。跟随系统偏好继续依据操作系统解析。

## Verification

主题对比度测试测量文本、填充操作与焦点颜色。组装后的无密钥浏览器场景检查两种配色和窄视口，并保留实际渲染配色及布局的可复现快照。GUI 回归覆盖既有交互。

## Alternatives considered

- 组件专属深色样式：重复维护色板，可能与已解析主题不一致。
- 动态扫描线或闪烁：持续干扰阅读与工具检查。
- 仅提供深色界面：移除现有浅色和跟随系统偏好。
