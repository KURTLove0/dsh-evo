# Agent Note: 通过提示词、技能与 MCP 组装业务 agent

Status: implemented

[English](2026-10-20-business-agent-composition.md) | 中文

## 问题

可复用的业务身份需要协同执行指令、所选技能和外部工具。通过预设发现项目技能，却使用无关的 Context 对象加载，会得到不同目录。进程级 MCP 命名空间保留也会阻止独立身份使用相同业务连接名称。此外，从活动注册表移除执行实例，不应隐藏工作区仍保留的会话。

## 决策

workbench-agent 定义在提示词指令和技能名称之外，还持有 MCP 传输配置。创建与编辑使用同一 schema 和同一次保存操作。能力发现读取配置预设的常驻作用域，执行读取实际 agent（智能体）的作用域并继承该预设。发现不创建会话或模型轮次。浏览器保留其他工作区无法解析的显式名称，执行则拒绝缺失能力。

每次任务在其 agent 作用域内挂载现有 MCP 客户端插件，并在发布前等待所有必要服务。agent 工厂持有回滚和完全停稳的释放过程，包括后续服务失败前已经建立的连接。stdio 在现有清理后环境之上接收显式环境变量值，并使用任务工作区；HTTP 接收显式请求头。部署持有 MCP 工具超时配置。配置值保存在宿主存储和执行快照中，不插入模型上下文。存储域使用版本 3，并拒绝旧数据。

身份的运行时指向“运行时”共用目录中的本地提供方。提供方声明其原生默认模型，模型覆盖必须属于该提供方；缺失默认值时必须显式选择。执行在创建 agent 前重新检查服务并解析选择，服务不可用或默认值缺失都不回退到部署的全局模型。浏览器并列展示运行时与模型选择，切换服务清空覆盖值。

基础组合包含使用已安装命令的 Codex 模型提供方。它复用共享子进程和 JSON-RPC 服务，通过 app-server 发现模型，并在任务工作目录和沙箱策略下执行临时原生线程，不下载 Codex wrapper。原生集成遵循 Codex 配置；Harness MCP 连接仍由作用域持有，但 Codex 适配器不将其 schema 安装为原生动态工具。

MCP 命名空间保留使用注册作用域；无作用域实例使用应用根。同一作用域内重名仍失败，独立任务可以复用名称，并保持确定的公开工具名称。这细化了 [MCP 客户端决策](2026-07-07-mcp-client-plugin.zh.md)中的命名空间作用域，同时保留该记录持有的传输、命名、重连和输出保证。

Host 流从工作区注册表派生会话保留关系。释放工作区持有的执行实例时发送空闲状态而非移除通知，使已完成任务的会话仍可选择。未附属会话保持移除语义。

## 考虑过的替代方案

**只保存 MCP JSON。** 只展示配置而不挂载，会让业务 agent 无法使用声明的工具，也将配置错误延迟到无关消费者遇到它时。

**全局安装身份连接。** 全局工具会向其他 agent 暴露某个身份的业务能力，多个身份使用相同名称时也会冲突。逐次执行持有连接，使释放和凭据相互独立。

**将运行时作为全局模型选择之上的展示标签。** 保存服务标签却派发到其他提供方，会使所选运行时失效。持久化路由并检查模型归属，才能将配置绑定到执行。

**为每个任务生成唯一工具命名空间。** 逐次执行名称可规避全局保留冲突，却使相同配置执行时的工具名称不断变化，并破坏权限策略的稳定性。逐作用域保留符合现有 ToolRuntime 注册模型。

**从浏览器移除每个已释放会话。** 仅凭是否常驻，无法决定删除工作区保留的历史。工作区归属提供了已提交的关系，无需恢复 agent 或增加线路格式。

## 影响

用户在首次创建表单中通过提示词、技能和 MCP 字段构造并保存业务 agent。必要连接失败会阻止模型执行，任务完成或停止会释放连接。MCP 环境变量和请求头值属于宿主配置数据，随定义复制，并非独立凭据库。现有任务输入框和历史归属仍由[任务检查决策](2026-10-20-workbench-agent-task-inspection.zh.md)持有。

## 验证

提供方测试通过 Loader 支持的工作台驱动真实 stdio 和 HTTP MCP 连接，检查模型上下文与持久化工具结果，从磁盘读取客户报告，并验证独立同名连接和回滚。界面测试覆盖技能及两种 MCP 传输的创建。无需密钥的正式应用浏览器场景创建身份、加载项目技能、对客户记录执行真实 MCP 进程、检查报告与会话，并记录创建和捕获配置快照。模型响应由脚本提供，不声称验证了真实模型行为。

原生运行时测试覆盖服务绑定、模型归属、提供方默认值、错误协议数据、目录发现、取消和进程清理。显式启用的只读 Codex 推理验证已安装 CLI 的登录与执行路径。浏览器预览读取其真实模型目录，并检查桌面和窄屏下的中文创建窗口。
