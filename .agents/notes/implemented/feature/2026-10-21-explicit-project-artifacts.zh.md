# Agent Note: 显式不可变项目产物

Status: implemented

[English](2026-10-21-explicit-project-artifacts.md) | 中文

## 问题

人工验收后工作空间文件仍可变化。文件路径或模型最终回复不能保留被评审的字节，登记回执丢失后再次捕获可能保存不同内容。

## 决策

独立的 Work Artifacts 服务负责显式文件登记及不可变编号快照。当前文件登记使用来源执行工作空间中的文件系统服务，检查路径包含关系和字节上限。执行关联记录操作人员选择的来源，不断言文件作者或验收。已验收评审提升读取指定不可变评审，复制其保留字节，不重新读取当前文件。产物存储域不拥有执行或会话日志状态。

登记比较预期版本，并随原始回执持久保存请求身份。相同请求在读取当前来源或文件前恢复原回执，包括追加较新版本或重启之后。完整记录和响应超限会拒绝，不截断或淘汰证据。目录分页绑定已提交代次及筛选。历史读取只依赖保留字节；当前文件观察是独立、显式且带时间的读取。

浏览器使用可选工作中心子插槽及独立产物页面。元数据刷新不读取文件。来源及连接变化将当前观察标记为过期。独立读取代次防止延迟响应覆盖较新选择。未确认登记跨页面重新挂载保留精确输入，必须显式重试或放弃本地请求；完整刷新重建已提交历史，不在浏览器存储持久保存路径。HTML 保持文本节点，二进制文件不执行。

[工作接单与评审决策](2026-10-20-work-center-intake-and-review.zh.md) 保留人工评审及修订所有权。[归档会话恢复](2026-10-21-archived-session-recovery.zh.md) 保留会话可见性所有权。两者均未被替代：产物快照保留独立选择的证据，不取代评审决定或会话账户。

## 考虑过的替代方案

**索引全部模型回复或终端日志。** 被提及的路径不能证明文件生成、字节或验收；操作人员显式登记才能记录目标文件。

**提升时重新读取评审路径。** 文件可能变化或消失，这会将验收附加到从未被评审的字节。

**重试时再次读取文件。** 回执丢失不能证明首次提交失败；持久请求回执恢复原操作。

## 影响

历史证据可在工作空间变化后保留，不提供可执行预览。文件及路径仍是受明确容量限制的主机私有资料。路径别名独立登记；分享、自动发现、导出、删除及完整文档渲染延后。

## 验证

服务测试覆盖字节编码、保留评审提升、重启及重试身份、版本冲突、路径包含关系、当前文件状态、目录代次分页、精确响应上限、严格持久解码及卸载。运行时和组件测试覆盖选择所有权、显式检查、过期观察、保留重试输入、纯文本预览及释放。完整浏览器场景使用终端生成文件、人工验收、删除原文件、独立当前文件版本、回执丢失恢复、二进制预览、双语控件、主题及窄屏，期间不产生额外模型请求。
