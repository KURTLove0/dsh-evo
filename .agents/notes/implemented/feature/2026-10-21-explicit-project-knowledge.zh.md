# Agent Note: 显式项目知识授权与捕获引用

Status: implemented

[English](2026-10-21-explicit-project-knowledge.md) | 中文

## 问题

历史会话和交付文件登记不能定义项目知识资料库。隐式搜索整个工作空间会绕过用户选择的范围；将路径重新读取作为引用，则会在文件变化后静默替换模型使用的资料。

## 决策

`work-knowledge` 负责显式单文件授权、不可变解码文本版本、字面行检索和精确引用。它组合可替换服务、本地文件系统/存储实现和类型化网关；可选 `tools` 入口消费同一服务。默认 Web 组合挂载 Provider、工具及[知识目录页面](../../../../packages/client/ui-work-knowledge/README.zh.md)，对应 [F11](../../proposed/feature/2026-10-20-outcome-oriented-workbench-product.zh.md#f11-project-knowledge)；其他组合可独立选用。

授权固定工作空间身份/路径及文件系统规范根目录/目标的不透明身份。登记只读元数据并启用选定文件。索引、检索与引用读取在服务执行器中检查启用状态，并要求在原工作空间完成一次新的有界可读文本观察。丢失、二进制、拒绝读取、越界、重绑定或映射改变的来源不能暴露保留内容。停用同样阻止旧引用读取与成功索引重试，但不会擦除既有会话已记录的材料。这是 Host 私有授权，并非团队身份系统。

成功索引保留解码 UTF-8 文本、该文本的 SHA-256、字节数、行数、捕获时间和连续版本。BOM 由文件系统解码负责；摘要不声称原始字节身份。LF 分行，前置 CR 保留。失败尝试保留诊断，与最近成功版本独立。来源修订串行处理变更；成功请求回执随捕获保留，最近失败回执保留到另一尝试提交。重试恢复原尝试和当前元数据，不重新读取变化内容。容量不足时拒绝，不淘汰，也不部分提交。

SQLite FTS5 在最新且启用、当前可读的捕获中做字面子串匹配；不足三个字符时使用字面扫描。参数绑定并转义 FTS 表达式，按来源身份和行排序，不声称语义相关性。每次显式有界检索根据已提交捕获建立可丢弃内存索引并关闭；规范文本与授权只存在存储域。检索返回完整行、是否还有结果、排除来源和独立的当前文件新鲜度。引用读取校验调用方工作空间、来源/版本、摘要和闭区间行范围，完整返回惰性捕获文本。

可选模型工具从执行 Agent 的会话目录取得空间权限，模型不能选择其他空间。普通工具调用与结果将精确资料保留在会话日志中，不自动注入提示词，不新增 Loop 行为或会话事件，也不依赖模型检索。惰性 JSON 只包含路径、引用和精确行，使用通用工具展示即可；渲染结果限制包含内容块包装。

[可移植执行环境决策](../architecture/2026-07-28-portable-execution-world-consumers.zh.md) 继续负责文件系统身份与解码。[显式项目产物](2026-10-21-explicit-project-artifacts.zh.md) 继续保留验收交付字节并允许独立历史读取；知识授权有意要求旧捕获也具备当前访问权限。[第三方 memory MCP 示例](2026-07-31-third-party-memory-mcp-examples.zh.md) 继续负责外部 Provider 互通，不变成知识来源 Provider。这些决策独立保留，没有被取代或归档。

页面使用既有赛博 Token 和页面/导航插槽。元数据、检索和引用回复分别绑定读取世代；空间和连接变化清除已读取文本。固定待确认输入跨页面重挂载保留，重连只读元数据。恢复的索引回执独立展示原尝试及捕获版本，不混同较新的来源元数据。整页重载会丢失本地待确认状态，已提交授权与捕获仍可查询。剪贴板失败时保留可选中的惰性引用文本。页面不在浏览器持久存储中保存项目材料。

## 考虑过的替代方案

**将会话搜索或交付产物作为资料库。** 两者均不提供显式文件知识授权或可撤销引用访问，其历史和来源责任也不同。

**每次引用都返回当前文件内容。** 当前访问决定能否读取，并不改变引用标识的精确捕获证据。独立新鲜度报告变化，不替换证据。

**增加向量、Provider 注册表或另一份持久索引。** 已确认的首批消费者需要本地 UTF-8 字面检查。仓库已有 SQLite；可丢弃派生索引避免第二持久事实和额外来源/Provider 协议。每次重建会产生索引构建开销，首个 Provider 因而限定为有界显式资料库。

## 影响

来源启用且原文件当前可读时，才能访问较早捕获文本。撤销影响后续操作，不影响先前日志。该基础实现不隐含递归扫描、外部格式/服务、自动索引、来源删除或共享。完整保留来源、资料库、查询、响应和工具渲染结果均受限；卸载等待已接纳操作完成后关闭存储。

## 验证

针对性 Provider/工具测试使用真实文件系统与 JSON 存储，覆盖中文/代码字面查询、不可变版本、重启和重试身份、撤销再启用、丢失/二进制/重绑定/越界来源、跨空间拒绝、严格持久解码、完整值限制、串行冲突、注册卸载与静止清理。无密钥真实 Web Loader 场景挂载构建产物，通过原生 Workbench Agent 验证精确检索/读取内容写入持久工具结果并进入后续模型输入，撤销后拒绝新执行。预期转录保留文本摘要与行引用。默认浏览器组合验证来源登记/索引、复制精确引用、脚本文本惰性展示、独立文件变化、旧版本保留、撤销与键盘再启用、页面重挂载后的登记与索引丢失回执恢复、相同重试参数及磁盘编辑前的原始索引文本，以及重载后的已提交元数据。中文、明暗配色和 320/375/414/768px 布局均有验证，不增加模型请求。
