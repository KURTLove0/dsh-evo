# Agent Note: 基于证据的工作诊断与显式完整重试

Status: implemented

[English](2026-10-21-evidenced-work-diagnosis.md) | 中文

## Problem

执行错误文字不能证明原因。工具被拒绝仍可能得到成功结果，后续会话消息也可能属于其他工作。传输响应未确认时重试，如果执行所有者不能识别原请求，还可能重复外部副作用。

## Decision

[工作中心](../../../../packages/business/work-center/README.zh.md#diagnosis-and-full-retry)仅在显式请求时投影来源持有的运行记录和持久化事件。稳定错误码与结束原因决定分类，文字作为原始证据保留，无法分类时保持未知。运行／轮次的终止事实与工具、模型尝试、节点及断言的失败观察分开。已恢复的观察不使完成运行变为失败。工具策略拒绝和结果拦截携带稳定错误码，保留既有面向模型正文。

智能体观察止于已记录结束序号。工作流子会话观察要求节点记录的时间区间。日志缺失、区间未知及单个投影超限明确返回；读取前限制子会话数量，完整报告超限会拒绝而非截断。报告是带时间戳的最后已知观察。刷新及重连使其过期，不调用模型、不探测连接，也不自动重新诊断。

重试是显式完整新运行，提交前提示重复副作用并展示脱敏配置。智能体所有者检查已确认的当前版本，结构化和自由文本工作均在提交时捕获配置。工作流所有者保留原始不可变发布版本、输入、反馈及执行路由。失败验收用例在新批次中保留验证模式与断言。两种路径都不恢复单个节点。

调用方请求标识与来源关系一起持久化。相同命令在当前归档或配置检查之前返回已提交回执，冲突复用拒绝。浏览器查看状态存储跨页面挂载和选择变化保留待处理命令。响应丢失时允许手动恢复同一请求，挂载与重连均不自动提交。完整应用重新加载会丢弃浏览器草稿。

[提交与验收决策](2026-10-20-work-center-intake-and-review.zh.md)继续负责独立人工验收、不可变交付证据及结构化提交。[任务检查](2026-10-20-workbench-agent-task-inspection.zh.md)继续负责任务草稿与捕获配置归属。[有界模型请求恢复](../architecture/2026-06-21-bounded-llm-request-recovery.zh.md)负责运行内部的自动请求尝试。这些决策仍各有价值，完整运行重试不取代它们。

## Alternatives considered

**按错误措辞分类。** 用户文字与提供方描述不是机器事实，不能证明配置、权限或提供方原因。

**将每个工具失败视为运行原因。** 模型可能恢复或绕过被拒绝工具完成任务，观察与终止状态必须分开。

**响应未确认时分配新请求。** 原运行可能已经提交，复用标识才能恢复而不重复准入工作。

**恢复失败节点或将验证改为普通执行。** 节点恢复需要独立的副作用与检查点语义；改变模式会丢失用户要验证的断言。

## Consequences

证据读取和重试复用执行所有者，不新增历史或调度器。智能体存储格式 5 与工作流存储格式 3 拒绝旧的预发布数据，不进行迁移。重试标识保证每个请求只准入一个运行，不保证运行内部外部副作用恰好执行一次。配置凭据仍由宿主持有，不进入诊断配置预览。

## Verification

所有者用例覆盖精确错误码投影、有界来源区间、证据不可用、并发与冲突请求、过期版本、重启恢复及验证语义保留。两种 SDK 保留重试检查点元数据。无密钥发布组合浏览器场景覆盖认证失败、工具拒绝后恢复、重试提交后响应丢失、页面重新挂载后手动恢复，以及失败验收用例重试。界面与管理器用例覆盖过期证据、修复导航及待处理命令保留。
