# Agent Note: 已认证的原生远程交接

Status: implemented

[English](2026-10-21-authenticated-native-remote-admissions.md) | 中文

## 问题

运行时目录可达不能授权任务，也不能证明文件、凭据、权限及执行历史的归属。转发普通浏览器 RPC 会继承面向浏览器的信任检查，而不是机器认证。调用方丢失交接响应后，也不能区分请求被拒绝还是原生任务已经执行。

## 决策

[Work Remote](../../../../packages/business/work-remote/README.zh.md) 能力向独立配置的接收部署发送完整任务。调用传输提供服务定义、HTTP 提供方及生成的网关；原生接收端拥有独立认证机器路由。[F10 提案](../../proposed/feature/2026-10-20-outcome-oriented-workbench-product.zh.md#f10-authenticated-remote-work) 描述浏览器流程及产品范围。

每次请求指定固定接收主机 UUID 及主体。接收端认证当前 Bearer 引用，在修改前检查预期身份，并在接纳或控制操作中执行精确工作空间／执行者授权。停止及工作流决定分别授权。Bearer 保留在凭据所有者及机器请求头中；任务输入、保留记录、响应数据及模型请求不包含传输凭据值。每次操作解析当前引用，并拒绝值歧义。

接收端绑定回环监听；调用方的非回环源地址要求 HTTPS，数字回环 HTTP 支持安全转发。转发凭据前拒绝重定向，以及带凭据或 URL 后缀的源地址。端点主机／主体检查防止错误部署先执行命令，再由调用方发现响应身份不匹配。普通[浏览器 API 信任策略](../architecture/2026-07-28-api-browser-trust-boundary.zh.md) 保持独立。

主体及调用方 UUID 在独立日志中拥有一个不可变目标及一个带命名空间的原生请求。原生交接前提交未确认状态。相同创建读取保留状态，不再次交接；冲突 JSON 内容按规范属性顺序比较并拒绝。显式恢复比较尝试次数并复用原生身份。响应丢失或回执写入失败后，原生幂等机制恢复已有执行。重启不自动重放不确定操作。接收端独立于历史保存主机 UUID，拒绝在同一域重新分配身份。

原生智能体及工作流服务拥有完整接收执行环境、凭据、已记录任务内容、权限及工作流审批。这与[可移植执行环境消费者](../architecture/2026-07-28-portable-execution-world-consumers.zh.md) 描述的共享文件系统／子进程提供方不同。远程工作派发至已有完整主机，不在本地拼接远程文件系统及进程句柄。

观察读取原生来源及已记录文本交付。来源或输出缺失分别标为不可用，观察时间不是执行结束时间。调用方验证完整响应、主机／主体、操作／结果关系、请求身份及原生来源关系。文件捕获内容保留远端。控制回执不变成执行成功或人工验收，控制响应丢失后必须读取权威状态。

默认 Web 组合挂载空机器列表的调用提供方及[远程执行页面](../../../../packages/client/ui-work-remote/README.zh.md)。无 React 的管理器拥有独立读取代际；共享视图状态跨页面重挂载保留草稿及精确未确认操作。每次调用除机器 id 外，还固定 Host／主体，重新分配配置 id 不会重定向保留的操作。重连只读取；显式创建恢复重复固定身份及内容，不确定控制需先读取权威状态再作新决定。获授权工作流查看返回原等待节点说明及实际输入，并独立标注不可用。原生审批、停止及交接恢复均需独立可见确认。

## 考虑过的替代方案

**按目录可达性代理既有浏览器 API。** 浏览器信任检查不建立机器主体及委托执行授权，必须显式指定接收权限与凭据。

**为未确认交接更换原生请求重试。** 原任务可能已经存在。持久原生身份让恢复指向同一任务，而不是授权另一次执行。

**在本地镜像远端队列及执行生命周期。** 这会产生两个可变所有者。接收日志拥有交接身份，既有原生队列及日志拥有执行。调用主机只持有配置的机器及显式请求输入。

**把远程路径当成本地文件，或同步所有工作空间。** 路径、凭据、权限及运行时状态属于接收环境。已记录文本可以跨机器协议传输，文件字节仍由原生远程界面管理。

## 影响

操作人员需同时配置接收端主体／授权及调用端固定机器／凭据引用。传输不创建人员账号、通用浏览器认证或团队共享。一个接收进程拥有持久根目录，不引入分布式租约，也不承诺任意外部副作用恰好执行一次。完整请求、响应、记录、历史数量、并发及网络上限显式拒绝超限，不淘汰证据。HTTP 断开终止等待，不撤销已接纳原生工作。卸载撤回接收路由、等待已接纳工作并关闭存储；调用提供方卸载取消并等待 HTTP 操作。

## 验证

真实 HTTP 及 JSON 存储测试覆盖凭据轮换与歧义、权限范围、预期身份、冲突／相同请求、重启、并发恢复、回执持久失败、完整字节上限、调用方断开、请求期限及等待卸载。通过 Loader 组合的双主机场景使用真实应用网关、认证传输、原生任务／工作流所有者及脚本外部模型响应。它只在远程工作空间写文件，响应丢失后恢复同一次原生任务，核对远程会话中的原任务输入，保留工作流发布／输入／审批，并证明本地没有执行。无密钥结果快照保留这些组合事实。

真实浏览器提交原生远程文件写入任务，跨页面重挂载保留调用方未确认请求，显式复用同一身份提交，并使用机器端点返回的原等待输入审批工作流。离线／重连不新增提交。默认组合验证中英文、明暗主题、键盘确认及 320／375／414／768px 布局。
