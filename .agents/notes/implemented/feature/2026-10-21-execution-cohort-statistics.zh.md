# Agent Note: 执行范围统计与有归属的用量观察

Status: implemented

[English](2026-10-21-execution-cohort-statistics.md) | 中文

## Problem

全机会话总计无法回答某个工作区或成员在指定日期内提交了多少工作。会话总计还包含后续对话，不能证明一次执行的消耗。缺失报告与不可访问来源不能使不完整范围看起来完整。

## Decision

[工作中心统计](../../../../packages/business/work-center/README.zh.md#run-statistics)通过执行所有者选择提交时间范围。包含起点、不包含终点的日期，以及工作区、来源和带来源类型的执行者筛选均在分页前生效。续页变化或来源容量错误丢弃该来源的部分范围；可用来源保持独立，完整报告分组或 UTF-8 字节超限拒绝而非截断。不持久化聚合历史。

排队、活动及已结束数量构成全部执行。等待人工处理属于活动运行的一部分：工作流等待持久化，智能体待处理通过当前连接观察。执行成功不能证明验证断言或人工验收。任务／配置生成及普通执行／验收验证数量保留各自含义。总耗时样本从提交到结束，包含排队和人工等待；排队样本从提交到首次已记录开始。缺失时间戳不变为零时长样本。

数量统计不读日志。独立的显式用量读取检查智能体精确结束事件之前的原始日志，以及已知节点区间内的工作流直接子会话日志。日志缺失、区间未知及读取预算耗尽保持明确；部分读取保留已观察用量及不完整覆盖。会话尝试数与配置上限描述读取范围。

[Token 投影决策](../architecture/2026-07-29-projected-token-usage-and-request-context.zh.md)继续负责规范的轮次／步骤替换及失败流样本。公开纯类型入口和区间辅助函数复用这些规则，不安装第二套计量器。已报告用量不代表完整账单，缺失请求和嵌套委派仍不在观察总和中。全机会话汇总保留独立的全时段口径。

现有统计模块声明运行范围子插槽。无 React 的管理器负责观察与迟到读取隔离，声明的查看存储负责未提交日期及维度控件。来源、筛选、待处理集合及重连变化只标记保留结果过期，不自动读取日志。原已提交筛选随结果保留。[任务提交决策](2026-10-20-work-center-intake-and-review.zh.md)负责执行聚合与验收分离，[任务检查](2026-10-20-workbench-agent-task-inspection.zh.md)负责逐身份历史与三十天活动。这些记录继续承担独立责任。

## Alternatives considered

**将全会话用量视为逐运行消耗。** 后续对话轮次和无关会话工作会抬高所选执行总量。

**聚合浏览器已加载的运行分页。** 分页与来源失败会改变分母，无法证明所选范围完整，因此由所有者在有界分页前筛选。

**页面刷新时检查每份日志。** 数量不需要会话正文。显式有界证据读取使开销和覆盖缺口可见，不新增持久化用量副本。

**另建指标历史。** 第二份可变执行记录需要与运行所有者和会话日志对账；有界按需范围满足当前本地消费者。

## Consequences

用户可按工作区、成员、工作流及本地提交日期比较已知工作，未知测量保持明确。过大范围需要缩小筛选。直接子会话区间不提供递归委派计量或历史人工响应时间；金额统计需要权威价格来源。本功能不新增持久格式、模型请求或外部遥测。

## Verification

来源所有者用例证明筛选在分页前生效、保留代次拒绝变化续页，以及目录不包含图和历史。聚合用例覆盖独立来源失败、带来源标识、时长样本、IANA 日期、精确分组和 UTF-8 上限、原始区间归属与读取预算耗尽。管理器及组件用例覆盖过期结果、筛选保留、证据缺失和来源失败展示。无密钥发布组合浏览器场景执行多个成员、配置生成、验收用例及等待工作流，再核对数量和五份用量报告，不额外调用模型。中文与窄屏布局使用同一实际应用。
