# @deepseek-ai/dsh-capability-health

[English](README.md) | 中文

配置观察与显式临时 MCP 连接探测。本包组合 `capabilityHealth` 服务定义、原生提供方和生成的 Remote 消费方；[浏览器插件](../../client/ui-capability-health/README.zh.md)负责呈现。

## 配置观察

`choices` 读取脱敏的已保存执行者。`check` 读取全局提供方配置，或一个明确的执行者版本和工作区。路由注册、本机可执行文件存在性、模型目录读取、所选任务依赖和凭证配置分别表示。目录读取可以访问既有元数据提供方，但不提交模型输入。命令存在性复用 daemon 包的当前宿主探测；远端目录不证明远程执行可用。

提供方设置地址选出与模型页相同的 `apiKeyEnv` 引用。凭证描述只返回存在性与来源，不返回值或有效性。授权流程和已存记录在不读取 payload 的情况下关联；无所有者的记录与环境认证保持未验证。单个目录或凭证失败不会隐藏其他成功结果。报告只包含封闭诊断键，不包含外部原始错误、地址、参数、环境变量值或请求头。

执行者检查委托其 preflight 读取准入事实。工作区不可访问时，依赖它的技能检查保持未验证；运行时不可用时，模型路由保持未验证。MCP 在显式探测前保持未检测。每份报告包含观察时间和可选的已捕获执行者版本／工作区。

## 临时 MCP 探测

`startProbe` 用执行者版本、工作区、服务名和非空 `HealthProbeId` 准入已保存服务。它在启动临时连接前检查归档、工作区和容量，并复用 [dsh-mcp-client](../../mcp/mcp-client/README.zh.md)。初始化与 ping 不列举、注册或调用工具，不创建任务会话，不发送业务输入。stdio 使用所选工作区，并将已保存的显式环境变量叠加到正常清理后的父环境。

相同请求标识返回已保留的准入或结果；字段冲突会拒绝。`readProbe` 恢复结果而不重复连接，未知标识（含宿主重启后）返回 null。`cancelProbe` 中止并等待清理。浏览器区分明确准入拒绝与响应丢失，不自动重发尚未确认的准入。

`HealthProbeRecord` 区分运行中与已结束观察。连接结果、完成时间和清理结果分别保留；服务有响应但清理失败时不会视为就绪。清理失败会阻止新探测，直到该宿主服务重新加载。卸载会中止并等待所持有探测与未完成读取。准入后监听器失败会被隔离；同步不变量失败在分发结束后仍然可见。

## 上限

正整数字段为 `maxItems`（1000）、`maxReportBytes`（262144）、`maxActiveProbes`（2）和 `maxProbeRecords`（200）。条目和 UTF-8 字节限制作用于完整报告或目录；超限拒绝，不截断。并发容量不能超过记录容量。正有限数 `probeTimeoutMs`（10000）限制初始化／ping；`probeCloseTimeoutMs`（5000）限制 SDK 关闭流程结束后的关闭事件等待。两者均受 Node 定时器上限约束。探测记录保留在内存中，直到服务重新加载；容量满时拒绝新准入，不驱逐用于恢复的标识。

## Model Experience

None, as 检查只读取配置和元数据，不提交模型输入或修改会话历史。

#### KV Cache effect

不改变模型请求前缀；MCP 探测不注册工具。

## Known Limitations and Deferred Work

- 观察是带时间戳的本地事实，不代表持续监控、凭证有效性、工具调用验证或远程执行。凭证引用发现沿用提供方现有的 `apiKeyEnv` 约定；未声明的认证保持未知。探测记录不跨宿主重启保留，配置读取使用各来源既有截止时间。详细故障证据与跨宿主诊断属于独立工作。
