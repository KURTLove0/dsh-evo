# @deepseek-ai/dsh-work-knowledge

[English](README.md) | 中文

通过 `workKnowledge` 与 `workKnowledgeGateway` 提供显式文件授权、不可变解码文本、字面检索和精确行引用。来源保存在 `work_knowledge` 存储域，格式版本为 1；SQLite FTS5 索引由已授权捕获派生且可丢弃。启动时不索引文件，也不调用模型。

## 来源与访问

`register` 固定调用方提供的来源 ID、工作空间身份与路径、相对文件路径，以及文件系统提供的规范根目录/目标不透明身份。登记即授予访问权限，只读取普通文件元数据，不捕获内容。相同登记恢复当前元数据；来源身份冲突或规范目标重复时拒绝。`setEnabled` 比较来源修订号；停用后保留元数据和历史，但拒绝内容读取与索引，包含较早成功尝试的重试。

新的索引尝试、检索与引用读取均通过 `ctx.fs` 重新检查原工作空间、规范包含关系与身份、当前普通文件可读性，以及有界 UTF-8 文本解码。丢失、不可读、二进制、重绑定或越界文件不能暴露保留内容。文件变化但仍可读时允许读取捕获版本，并独立提供带时间的 `matching`/`different` 观察。这是单 Host 私有授权，并非多用户 ACL；撤销不能擦除先前会话已记录的结果。

## 捕获与检索

`index` 等待一次有界读取，提交不可变文本、解码文本 SHA-256、字节数、行数、时间及连续版本。BOM 语义由文件系统解码负责；摘要并非原始文件摘要。按 LF 分行，保留前置 CR。失败尝试提交诊断，不替换成功捕获。来源修订比较拒绝竞争写入。成功请求回执随捕获保留；最近失败尝试可恢复，直到另一次索引尝试提交。重试返回原尝试和当前来源元数据，不重新读取磁盘新内容。存储失败会拒绝，不声称捕获已获确认。

`sources` 读取不含内容的元数据。`search` 选择一个工作空间中最新且启用的捕获，重新检查当前访问，报告排除来源，将查询去除首尾空白后，对查询和行使用 JavaScript 小写转换，再在单行内匹配字面子串；不做 Unicode 规范化或完整大小写折叠。至少三个 Unicode 字符的查询使用 SQLite FTS5 trigram；更短查询使用字面扫描。结果按来源 ID 和行号排序；显式命中上限排除后续匹配时返回 `more`。不提供语义排序或自动重建索引。每次显式有界检索重建内存索引，并在完成后关闭。

`read` 检查调用方工作空间、来源、精确版本、文本摘要和从一开始的闭区间行范围，完整返回惰性捕获行及当前文件新鲜度。不执行 HTML，也不将来源指令导入提示词。保留值和返回值均与内部对象分离；超限时拒绝，不截断引用证据。操作串行处理授权变更，并在存储域卸载前等待已接纳操作结束。

## 配置

正整数限制：`maxSources`（跨空间 64 个）、`maxVersions`（每来源 20 个）、`maxFileBytes`（131072 个解码 UTF-8 字节，并保守预检原始大小）、`maxRecordBytes`（完整来源 4194304 字节）、`maxTotalBytes`（全部保留来源 16777216 字节）、`maxResponseBytes`（每个完整响应 1048576 字节）、`maxQueryBytes`（字面查询 512 字节）及 `maxHits`（50）。容量不足不会淘汰历史。响应容量必须容纳完整选定元数据或引用行。

工具插件的 `maxOutputBytes`（1048576）独立于 Provider 响应容量，限制完整渲染内容块。超限会失败，并要求选择更少命中或行。

## 模型体验

### 知识工具与结果

#### 模型可见内容

可选入口 `@deepseek-ai/dsh-work-knowledge/tools` 注册使用通用工具展示的 `knowledge_search` 和 `knowledge_read`。工作空间权限来自执行 Agent 的会话目录；模型提供的空间不能扩大访问。检索返回字面行命中和引用，读取返回精确捕获文本。来源文本仅作任务材料。普通 `tool/call` 与 `tool/result` 事件保留检索资料，不新增会话事件类型。浏览和索引不调用模型。精确参数见生成的[工具 Schema](../../../docs/tool-catalog.zh.md#deepseek-aidsh-work-knowledge)。检索不依赖模型执行。

#### Token 影响

可选工具描述和 Schema 带来每次请求的固定开销。检索和读取结果将完整选定元数据与捕获行追加至普通请求历史。

#### KV 缓存影响

注册工具会改变可用 Schema 前缀。工具结果追加普通日志历史；来源登记、索引与浏览不改写既有会话前缀，也不将整个资料库注入系统提示。

## 已知限制与待办

- 仅支持显式选择的单个 UTF-8 文件，不提供递归扫描、URL、MCP/Office 导入、向量、自动后台索引、共享或删除。当前文件丢失或不可读时，历史内容读取同样被拒绝。有界资料库侧重显式资料检查，不用于大仓库搜索；每次检索重新打开 SQLite 会产生索引构建成本。默认 Web Bundle 挂载[知识目录页面](../../client/ui-work-knowledge/README.zh.md)、Provider 和可选工具入口。
