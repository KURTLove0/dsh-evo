# @deepseek-ai/dsh-work-artifacts

[English](README.md) | 中文

通过 `workArtifacts` 与 `workArtifactGateway` 显式登记项目文件。服务在格式 1 的 `work_artifacts` 存储域中保留不可变字节及执行来源，不执行任务、不写工作空间文件，也不从模型文本推断产物。

## 登记与历史

登记固定操作人员提供的路径与工作空间。每个版本保留字节数、SHA-256、编码、登记时间及来源执行元数据。当前文件登记通过文件系统服务读取已结束执行的工作空间，检查路径包含关系及原始字节上限。关联执行不证明文件作者，也不构成人工验收。

已验收评审提升读取指定的已提交人工评审，保留其捕获字节、评审修订号、交付版本及评审时间，不重新读取当前文件。因此，工作空间文件变化或删除后仍可查看历史。UTF-8 预览保留开头的字节序标记；无效 UTF-8 或包含 NUL 的文件使用 base64。消费者以纯文本展示内容，识别二进制内容而不执行。

写入比较 `expectedVersion`，并随 `requestId` 保留原始回执。相同请求的重试在访问当前来源或文件前返回原回执，包括追加新版本或主机重启之后。复用身份提交不同输入会拒绝。同一工作空间和路径的重复登记必须显式追加到已有身份。容量错误保留全部历史，不自动淘汰。通知在持久提交后发出，观察者错误不使回执失效。卸载等待已接纳操作完成。

## 查询与观察

查询返回最新版本的无内容元数据，可按文本、工作空间、来源类型及最新版本登记方式筛选。分页游标绑定已提交目录代次和筛选条件，目录变化及主机重启会使其失效。读取返回一个指定快照及无内容的版本历史，不暴露内部请求哈希。元数据查询不读取当前文件。

`inspectCurrent` 显式比较当前文件与所选历史版本，保留观察时间及相同、不同、不存在或不可用状态。它不修改历史，也不把之前的人工验收结论转移给新文件。

## 配置

正整数上限：`pageSize`（25）、`maxPageSize`（100）、`maxArtifacts`（1000）、`maxVersions`（20）、`maxFileBytes`（131072 原始字节）、`maxRecordBytes`（完整持久记录的 4194304 UTF-8 字节）及 `maxResponseBytes`（完整响应的 1048576 UTF-8 字节）。`pageSize` 不得超过 `maxPageSize`。超限会拒绝而不截断证据。历史读取也受响应容量限制。

## 模型体验

无。登记、预览和当前文件检查不调用模型，也不修改会话输入。

#### KV Cache 影响

不产生模型请求，也不修改会话前缀。

## 已知限制与延后工作

- 单主机私有目录，文件快照容量有界。不支持自动发现、分享、删除、导出、可执行预览或完整文档渲染。路径与快照可包含用户资料。路径别名是独立的操作人员身份。当前文件读取需要原工作空间及已结束的来源执行；历史读取使用保留字节。
