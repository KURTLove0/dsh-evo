# @deepseek-ai/dsh-work-remote

[English](README.md) | 中文

已认证完整任务传输与显式启用的原生接收端。`remoteWork` 和 `remoteWorkGateway` 向明确配置的执行机器派发任务；`./receiver` 提供仅面向机器的 `/remote-work/v1` 路由。仅提供目录的运行时机器不授权执行。[子系统参考](../../../docs/subsystems/work-remote.zh.md) 负责协议类型；[F10](../../../.agents/notes/proposed/feature/2026-10-20-outcome-oriented-workbench-product.zh.md#f10-authenticated-remote-work) 描述完整浏览器流程。

## 组合与凭据

在调用主机挂载根插件，显式配置 `peers`：本地标识／名称、规范源地址、固定的接收主机 UUID、固定主体标识及凭据引用。非回环地址要求 HTTPS；数字回环 HTTP 支持安全隧道。源地址中的凭据、路径、查询及片段会拒绝；重定向不接收下一次请求。调用方每次操作解析传输 Bearer。机器说明只显示引用／存在性及所有权，不显示值。机器经 Cordis 配置；运行时机器目录保持独立。

在远端主机显式挂载 `./receiver`，配置 `hostId` 及 `principals`。每个主体指定凭据引用、精确工作空间／智能体／工作流授权，以及分别必填的 `allowStop`／`allowWorkflowDecisions`。启动时检查原生引用及主体／凭据引用分配唯一性。每次请求按当前凭据值认证；缺失、格式错误或轮换后重复的秘密均失败。Bearer 要求至少 32 个可用于请求头的字符。接收端要求回环 Web 监听。使用 SSH 转发，或仅暴露机器端点的 TLS 代理；普通浏览器 API 信任属于独立策略。

所有目标及来源身份均属于接收主机。原生智能体／工作流服务拥有模型凭据、工具、权限、任务日志及原会话。接纳、检查、恢复及控制操作内部再次执行授权检查。工作流目标保留精确发布版本及 JSON 输入。检查返回记录的文本、独立标注的不可用证据及读取时间；文件字节保留远端。原生工作中心检查可能读取有界交付证据，但文件捕获内容不会跨此协议传输。

## 持久化与生命周期

主体及调用方 UUID 标识一次提交。原生交接前，在同一记录保存固定输入、规范摘要、带命名空间的原生请求及未确认状态。相同创建返回该记录而不再次交接，冲突复用会拒绝。显式恢复比较尝试次数并复用固定原生请求。原生幂等机制可在响应丢失或确认写入失败后恢复已有执行。已接纳回执与执行状态及人工验收相互独立。

接收端即使为空也持久保存主机身份；在同一域变更身份会拒绝。主体只能查看当前仍获授权的保留提交。撤销授权拒绝访问，但不删除历史。HTTP 断开不撤销已排队的原生工作。重启不会自动重试不确定状态。调用请求同样固定 Host／主体，重新分配机器 id 会在转发前被拒绝。获授权工作流查看返回原等待节点、说明及输入，并独立标注不可用状态。停止及精确尝试的工作流决定需要独立授权；回执丢失后需读取权威状态。普通智能体工具审批保留在远端应用的原生交互所有者中。

接收端卸载撤回路由、销毁未完成请求、等待已接纳处理及原生命令结束，再关闭日志。调用提供方卸载会取消并等待网络操作。网络期限只终止等待，不终止远程执行。完整 JSON 在保留或传输前受限；超大响应失败，不截断或淘汰证据。传输失败及任意远端异常不暴露原生诊断文本。

## 上限

调用端配置包括 `timeoutMs`（10000）、`maxRequestBytes`（262144）、`maxResponseBytes`（1048576）及 `maxInFlight`（16）。接收端配置包括 `maxRequestBytes`（262144）、`maxResponseBytes`（1048576）、`maxRecordBytes`（262144）、`maxSubmissions`（100）、`maxInFlight`（16）及 `bodyTimeoutMs`（10000）。上限为正安全整数，计时值还需满足 Node 计时器范围。字节限制包含完整机器信封或保留的私有记录。容量阻止新增工作，不删除证据。响应容量无法表示最小配置回执时，启动拒绝。

## Model Experience

间接影响，经过 [dsh-workbench-agent](../workbench-agent/README.zh.md#model-experience) 及 [dsh-business-workflow-local](../business-workflow-local/README.zh.md#model-experience)，由它们在接收主机记录固定任务内容。

#### KV Cache effect

传输、目录及检查不添加模型消息。原生接收端创建普通远程会话，由执行所有者决定提示词及前缀。

## Known Limitations and Deferred Work

- 每个持久根目录只由一个接收进程拥有。不提供分布式租约、未确认命令自动重试、节点检查点恢复、文件同步／下载、任意文件系统代理或人员／团队身份模型。不承诺原生任务内外部副作用恰好执行一次。默认 Web 应用挂载空机器列表的调用提供方及[远程执行页面](../../client/ui-work-remote/README.zh.md)，接收权限需显式配置。
