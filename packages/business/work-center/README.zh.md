# @deepseek-ai/dsh-work-center

[English](README.md) | 中文

跨执行来源的工作目录与持久化人工交付验收。Web bundle 在现有[智能体](../workbench-agent/README.zh.md)和[工作流](../business-workflow-local/README.zh.md)执行服务之上装配 `workCenter` 提供方及生成的 `workCenterGateway` Remote 消费方。来源服务负责执行，本包负责验收记录。

## 目录与任务提交

`query` 在合并有界来源分页前，先筛选来源、工作区和执行状态。工作流确认与当前连接观察到的 `attentionSessionIds` 中正在运行的任务优先，其余按已提交执行更新时间倒序排列。智能体更新时间取创建／开始／结束，工作流取持久化检查点；人工验收时间独立保留。标识包含来源类型。游标属于原筛选条件、分页大小、待处理会话集合和两个来源目录代次。执行变更或宿主重启会使游标失效，要求调用方刷新，避免静默遗漏移动的记录。未提供待处理会话观察时，不推定智能体交互状态。来源读取失败会明确返回，并暂停续页直到刷新；成功来源为空不会掩盖另一个来源的失败。`executors` 返回名称、版本、指令、运行时／模型、技能和 MCP 名称，不返回连接环境变量或请求头的值。`options` 返回部署配置的分页数量。

浏览器通过智能体所有者提交结构化任务简报。执行前检查与提示词预览不会执行任务；真正提交时会再次检查执行者版本和依赖。普通会话的批准、提问及计划审查仍在来源会话处理。工作流决策转发精确的等待尝试标识。

## 证据与验收

`detail` 读取智能体运行所属序列区间内最后一条持久化助手响应，或已结束工作流的已提交输出。智能体简报可以声明工作区文件。这些文件在检查时读取，逐个限制大小，并以 UTF-8 或 base64 原始字节和 SHA-256 指纹留存。它们是检查时的证据，不是执行时的文件历史。缺失、工作区以外、过大或不可读的文件会明确标记；存在不可用的期望文件时拒绝验收通过。二进制内容只留存，不渲染或执行。完整交付过大时不可验收，不会截断后作为完整证据。

交付版本由来源引用、已记录输出、标准、断言和文件证据共同计算。验收比较该版本与当前人工验收修订号，然后在格式 1 的 `work_center_reviews` 域内原子保存完整交付和决策。冲突决策会拒绝；相同决策标识在重试与重启后返回原已提交回执。历史验收证据不随工作区后续修改而改变。操作者归属为本地宿主操作者，不代表已认证的团队身份。

保存意见不会执行任务。明确创建修改任务时，会新建有关联的智能体任务，或使用原工作流发布版本与输入，携带已记录意见和原输出重新执行。智能体修改任务预览完整追加后的简报，并要求所选配置的当前版本。原运行与其验收记录独立保留。

<a id="diagnosis-and-full-retry"></a>

## 诊断与完整重试

`diagnose` 读取来源服务持有的执行与持久化证据，不调用模型、工具或 MCP。分类依据稳定错误码和已记录结束原因，无法分类的文字保持未知。工具和模型尝试的失败属于观察，即使执行最终成功也会保留。智能体会话止于运行的 `settledSeq`；工作流子会话观察使用节点记录的开始／结束时间。缺失证据、未知区间和单个投影超限明确返回；汇总条目或完整报告字节超限会拒绝读取，不返回截断证据。`maxDiagnosisSources`（50）限制子会话读取数，`maxDiagnosisFindings`（200）限制观察条目，`maxDiagnosisBytes`（262144）限制 UTF-8 JSON 证据字节。

显式重试命令将调用方请求标识转发给执行所有者。智能体重试要求已确认的当前配置版本。工作流重试保留原始不可变发布版本、输入、反馈、执行路由及适用的验证断言。每次重试都是完整新运行，不恢复单个节点，不修改原验收。浏览器在提交前展示脱敏配置并提示重复副作用。

<a id="run-statistics"></a>

## 运行统计

`statistics` 以包含起点的 `from`、不包含终点的 `to`、工作区、来源及带来源类型的执行者筛选提交时间范围。来源所有者在有界分页前筛选；续页失效或来源超限会使整个来源不可用。可用来源独立贡献，不将不可用来源视为零运行。日期按请求的 IANA 时区分组；同一范围生成总计及日期／工作区／执行者分组。各组使用最近提交运行所观察到的执行者名称；带来源类型的标识保持区分。执行者分组先按观察到的名称排序，再按带来源类型的标识排序。

排队、活动和已结束数量构成全部运行。等待人工处理属于活动运行的一部分：工作流等待为持久状态，智能体待处理来自当前连接观察。成功仅依据执行状态，与验证断言及人工验收分开。任务／配置生成及普通执行／验收验证数量分别保留。总耗时从提交到结束，包含排队和人工等待；排队样本止于首次已记录开始。缺失或不一致的时间戳不计入时长，保留有效样本数。

数量统计不检查会话日志。`usage: recorded` 显式读取原始日志，受 `maxStatisticsSessions`（100）限制。智能体止于精确已记录结束事件；工作流直接子会话使用已知节点开始／结束时间。区间未知及读取失败保持不可用，读取预算耗尽保持未完整检查；已经观察到的部分用量与该覆盖状态一起保留。结果返回尝试读取的会话数及上限。复用规范 Token 计量折叠，替换重复轮次／步骤样本，并保留失败流中的用量块。不虚构缺失报告、后续会话工作或嵌套委派用量，也不将其声称为完整账单。`statisticsChoices` 只返回安全名称与标识，不返回配置或历史。

`maxStatisticsRuns`（每个来源 5000）、`maxStatisticsGroups`（三个维度合计 1000）和 `maxStatisticsBytes`（完整响应 1048576 个 UTF-8 字节）限制读取与输出。来源超限丢弃该来源的部分范围，分组／字节超限拒绝报告。不持久化聚合结果。

## 配置

所有限制均为正整数：`pageSize`（25）、`maxPageSize`（100）、`maxReviewDecisions`（10000）、`maxRecordBytes`（每个来源的完整验收历史 4194304 字节）、`maxDeliveryBytes`（完整交付证据 262144 字节）和 `maxArtifactBytes`（每个文件 131072 字节）。`pageSize` 不得超过 `maxPageSize`；来源提供方也必须允许所选分页数量。容量错误拒绝后续写入，不删除历史。卸载先排空串行决策，再关闭存储。

`source` 返回独立的执行身份、名称、工作空间、会话及状态，不读取会话或文件。`review` 读取指定已提交评审修订，不重新捕获字节。这些方法支持独立服务显式登记产物。

## Model Experience

间接通过 [dsh-workbench-agent](../workbench-agent/README.zh.md#model-experience) 和 [dsh-business-workflow-local](../business-workflow-local/README.zh.md)，将明确提交的修改意见与原已记录输出写入新执行会话。目录读取、执行前检查和人工验收不调用模型。

#### KV Cache effect

修改任务创建独立执行会话。验收写入不使已有模型请求前缀失效。

## Known Limitations and Deferred Work

- 仅支持单宿主；不提供团队授权、远程宿主聚合、离线通知、历史文件恢复或自动合并发布。文件检查由期望路径显式启用。工作流字符串输出直接留存，不解释为文件路径。验收历史和证据有容量上限；归档与导出属于后续工作。
