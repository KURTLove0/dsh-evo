# @deepseek-ai/dsh-work-templates

[English](README.md) | 中文

私有、带版本的任务与工作流模板。`workTemplates` 提供方及 `workTemplateGateway` Remote 消费方将可复用内容与执行、人工验收分别保存。

## 内容与修订

任务模板包含经过校验的结构化简报，不保存执行者、工作区分配、MCP 环境变量或连接请求头。工作流模板保存完整的不可变发布定义，以及原工作流和发布版本标识。只能选择已发布定义；草稿不能保存为工作流模板。

每次保存内容都追加不可变的编号版本。记录修订号也包含归档和恢复决策。写入比较 `expectedRevision`；相同 `requestId` 的重试返回原收据，即使已有新版本或宿主重启。请求标识用于其他编辑会被拒绝。归档保留历史，恢复前不能更新或创建副本。同一历史不能在任务和工作流类型之间切换。

`list` 返回包含归档记录的有界摘要；`read` 返回独立的完整版本历史，不公开内部变更指纹。`sources` 仅公开工作流名称与发布标识。变更通知在持久化提交后发送，观察者失败不影响已确认写入。卸载先等待编辑完成，再关闭存储。

## 复用

任务表单将所选内容版本载入可编辑简报，并保留明确的模板标识与版本。工作区和执行者单独选择。编辑副本内容不会改写来源版本。智能体所有者检查依赖与配置版本，将提交简报随运行持久化；提示词构造和执行仍由该所有者负责。

`copyWorkflow` 将固定发布版本的幂等复制交给工作流所有者。新建的独立草稿记录来源发布与模板版本，没有发布或运行。操作者通过现有工作流工作台检查、编辑、发布并明确启动。编辑副本不改变任一来源。代码审查、文档整理和数据文件报告样例只有可编辑指令，不代表已安装能力或已配置模型路由。

## 配置

正整数上限：`maxTemplates`（200 条记录）、`maxVersions`（每条记录 50 个内容版本）与 `maxRecordBytes`（最小 1024 字节，完整记录默认 1048576 字节，包含保留的请求收据）。容量不足时拒绝写入，不删除已有版本。存储域 `work_templates` 使用格式 1，拒绝无法识别的记录。

## Model Experience

间接影响，经由 [dsh-workbench-agent](../workbench-agent/README.zh.md#model-experience) 和 [dsh-business-workflow-local](../business-workflow-local/README.zh.md)，它们通过原生执行路径记录明确提交的副本内容。

#### KV Cache effect

保存、检查、归档或复制模板不调用模型，也不改变现有会话前缀。明确提交任务和执行已发布工作流会创建各自的会话。

## Known Limitations and Deferred Work

- 仅限单宿主私有内容；不提供分享、外部导入、敏感信息扫描、自动安装能力、模板导出、删除或历史归档。期望输出路径和任务背景是用户材料，可能包含敏感信息。浏览器任务草稿不跨刷新保留。工作流复用创建草稿，并要求原不可变发布仍然可用。
