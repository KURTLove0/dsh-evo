# @deepseek-ai/dsh-client-ui-work-artifacts

[English](README.md) | 中文

基于 [dsh-work-artifacts](../../business/work-artifacts/README.zh.md) 的项目产物目录及可选工作中心登记控件。侧边栏打开工作空间、来源和登记方式筛选以及纯文本历史预览。

## 界面

`work-center.delivery.artifacts` 插槽属于工作中心。可选贡献从所选已结束执行登记当前文件，或提升明确选择的已验收评审中捕获的文件。登记保留来源，必须显式操作。目录展示有界登记元数据、已提交筛选、版本历史、字节数、摘要、时间及仍在会话列表中的来源会话链接。

只有显式请求才检查当前文件。刷新元数据和重连不读取文件。来源或连接变化将保留的观察标记为过期。新登记的当前文件不继承历史人工验收结论。文本通过 React 文本节点展示，包括 HTML 源码；二进制内容只标识，不执行。

无 React 依赖的运行时管理器分别管理目录、预览、观察和写入。延迟响应不能替换较新的选择。读取错误保留上次已提交筛选和记录。未确认登记在声明的视图存储中保留来源、路径、预期版本和请求身份，可跨页面重新挂载。显式重试恢复原回执，放弃本地输入不取消已提交主机写入。完整刷新浏览器丢弃未提交控件及未确认请求，已提交历史仍保存在主机。插件卸载时释放所有贡献、订阅和管理器。

## 模型体验

无。页面渲染、登记、预览和显式文件比较不修改模型输入。

#### KV Cache 影响

不产生模型请求，也不修改会话前缀。

## 已知限制与延后工作

- 单主机私有文件，不支持分享、导出、自动发现、实时 HTML、文档执行、离线写入或持久浏览器草稿。所有容量限制属于主机。原始会话不可用时禁用导航链接，仍展示保留的来源。
