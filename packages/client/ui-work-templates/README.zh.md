# @deepseek-ai/dsh-client-ui-work-templates

[English](README.md) | 中文

基于 [dsh-work-templates](../../business/work-templates/README.zh.md) 的私有模板页与可选任务表单控件。侧栏打开已保存历史、归档／恢复操作和不可变工作流发布选项。

## 界面

模板库按类型展示任务与工作流模板，包含已归档历史。选择明确的内容版本会保留其原名称和内容。工作流副本要求指定目标工作区和名称；复制只创建可编辑草稿，另有入口打开已有工作流工作台，以便发布和执行。

检查页先展示任务字段，以及工作流目标、输入和步骤，再提供复制操作。完整 JSON 定义放在默认收起的高级区域。

`work-center.intake.templates` 插槽由工作中心拥有。本插件提供任务模板选择、明确载入当前简报、另存新模板或新版本，以及可编辑的代码审查／文档／数据报告样例。载入替换任务内容，保留已选执行者和工作区，并使已有预检预览失效。提交运行保留来源模板版本。归档和恢复使用修订检查；传输重试复用同一变更标识。

权威数据位于不依赖 React 的 runtime 管理器。选择控件与未提交名称使用声明的视图 store，不跨刷新保留。宿主事件与重连会刷新已提交数据。断连及读写失败明确展示；加载中与读取失败不会显示目录为空。工作流选项或样例失败时，成功读取的模板仍可使用。执行仍需普通任务表单检查。插件随 fiber 释放注册、监听器与管理器。

未确认的变更与复制请求由声明的视图 store 保存，跨页面重新挂载保留。内容未改变的重试保留原修订号与请求体，即使提交通知先到达。旧确认不会清除新请求。放弃重试并刷新会建立新的编辑意图，不取消已提交的宿主操作。

## Model Experience

间接影响，经由 [dsh-work-templates](../../business/work-templates/README.zh.md#model-experience)，它保存供明确提交任务和独立发布工作流副本使用的内容。

#### KV Cache effect

渲染、载入草稿字段和模板编辑不改变模型历史。明确提交后由执行所有者决定提示词。

## Known Limitations and Deferred Work

- 不提供分享、离线编辑、持久化浏览器草稿、导入／导出或自动执行。选择工作区和执行者后，才能通过任务表单检查模板可执行性；工作流副本使用既有发布／运行控件。内容和历史容量上限均由宿主提供。
