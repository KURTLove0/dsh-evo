# @deepseek-ai/dsh-client-ui-work-remote

[English](README.md) | 中文

通过既有侧栏及页面插槽组合的[远程执行](../../business/work-remote/README.zh.md)页面。默认 Web 应用挂载调用提供方，机器列表为空；操作人员配置已认证机器及独立远端接收端。运行时目录条目不授予执行权限。

## 界面

选择配置的机器，核对固定 Host／主体与凭据引用／存在状态，再选择获授权的远程目录及执行器。智能体提交固定所选修订及结构化任务；工作流固定正式发布版本及显式 JSON 输入。目录路径、运行时、技能及 MCP 名称描述远程执行环境；模型凭据保留在远端。目录、历史与原提交详情分别保留新鲜度及错误。

无 React 的 runtime 管理器拥有观察结果及读取代际。声明式视图 store 跨页面重挂载保留草稿及固定权限身份的不确定操作。重连只读取，不重复写入；相同进行中命令合并。显式创建恢复复用原 UUID 与内容，原生交接恢复比较保留的交接次数。重新分配机器 id 不会把保留操作发往不同 Host 或主体。清除本地不确定记录不撤销远程工作。

查看原生状态、会话／执行标识、读取时间及已记录文本，并区分接纳和验收。文件与普通工具审批留在远端原生应用。工作流审批上下文包含原等待节点、说明及实际输入；停止、恢复和批准／拒绝均需显式确认。控制回执缺失时，需先读取权威状态再作新决定。界面使用赛博主题语义变量、中英文标签、可见焦点和窄屏堆叠布局。

## Model Experience

通过 [dsh-work-remote](../../business/work-remote/README.zh.md#model-experience) 间接影响模型，远端原生所有者记录已提交任务内容。

#### KV Cache effect

渲染及查看不产生模型请求。原生执行所有者决定提示及前缀。

## 已知限制与延后工作

- 草稿及本地未确认操作只存于加载插件的生命周期，完整重载会丢失；已提交远程历史仍可发现。不支持离线写入、自动轮询／重试、文件传输、普通远程工具审批代理或多人身份系统。
