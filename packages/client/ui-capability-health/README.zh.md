# @deepseek-ai/dsh-client-ui-capability-health

[English](README.md) | 中文

通过 [dsh-capability-health](../../business/capability-health/README.zh.md) 提供带时间戳的配置观察与显式连接检查。底部入口打开独立主页面，使用共享赛博主题变量、带标签控件、可见焦点和窄屏卡片布局。

## 交互

打开页面只读取执行者选项。全局与执行者检查均需明确操作；所选范围要求已保存执行者和工作区。页面分别显示路由注册、命令存在性、目录、凭证存在性和任务依赖，不将凭证已配置或目录可读显示为认证有效或执行成功。来源变化会将已有报告标为过期；断连保留带时间戳的最后已知观察。

MCP 在用户要求前保持未检测。新探测使用已检查的执行者版本与工作区；准入再次验证两者。连接与清理结果独立显示。不依赖 React 的运行时管理器在页面重新挂载后保留已提交标识，丢弃过期配置读取，并防止较旧的运行中确认覆盖已完成结果。重连只读取既有标识，不重发探测；未知标识不会启动工作。宿主明确拒绝和未确认的传输失败分别处理。切换选择范围后，历史仍提供取消和恢复结果的入口。

修复操作通过 `settingsPanel.open` 打开现有智能体页面、工作区选择或设置外壳已注册的模型／运行时／通用分区，不修改配置。选择和显示筛选草稿使用声明的视图 store，不跨刷新保留。权威报告与操作观察留在运行时管理器和宿主所有者中。插件卸载会释放注册与监听器；关闭页面不会取消宿主持有的探测。

## Model Experience

None, as 页面只显示配置和连接观察，不提交模型输入。

#### KV Cache effect

渲染与探测不改变模型历史或注册工具。

## Known Limitations and Deferred Work

- 不提供后台监控、自动重试探测、跨浏览器刷新保留的历史或认证有效性保证。宿主探测保留与容量上限由服务配置决定。尚未确认的结果仅在宿主仍保留其标识时可恢复。
