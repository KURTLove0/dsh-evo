# @deepseek-ai/dsh-client-ui-work-center

[English](README.md) | 中文

基于 [dsh-work-center](../../business/work-center/README.zh.md) 的工作中心页面和侧栏入口。独立智能体与已发布工作流保留各自的执行所有者。


工作中心在交付旁声明可选 `work-center.delivery.triggers` 列表插槽。触发插件接收所选原执行及禁用状态；显式准备操作打开触发页面，不添加另一份任务录入表单。

## 界面

页面集中展示待批准、待回答、计划审查的会话，以及分页读取的工作流确认。会话事项打开原会话；工作流决策使用所选的精确等待尝试。待处理入口只描述当前连接已知会话与已加载工作流页，不声称全局完整数量。断线与来源错误明确可见。

来源、工作区和执行状态在目录分页前筛选。待处理任务与工作流确认优先，其余按执行更新排序。每行标明创建时间和已提交执行更新时间；最后读取时间仅表示目录观察时间。已知待处理会话集合变化时刷新分页。执行状态与人工验收状态分别展示。运行详情呈现已记录输出、提交时的验收标准、工作流断言、检查时的文件快照，以及验收时保存的证据。内容按文本渲染；二进制证据不执行或嵌入页面。

新任务显式选择执行者与工作区，填写目标、背景、期望文件路径、验收标准和限制。检查与预览只读取依赖和完整规范化任务提示词，不执行任务。MCP 连接在启动执行时才检测。编辑会使预览失效；提交要求其执行者版本。草稿在应用内切换页面后保留，刷新后丢失。收起保留草稿，清空需要显式操作。请求标识在传输重试时保持，直到草稿修改或提交得到确认。

验收通过与要求修改保存独立的人工决策。要求修改必须填写意见。保存不会执行任务。智能体修改任务打开可编辑简报，并展示原配置与本次脱敏配置。工作流修改任务需单独确认，使用原发布版本和输入重新执行。文件变化后仍可查看验收时的证据。执行操作要求连接正常。

页面使用共享语义主题变量、可见键盘焦点、触控目标和窄屏堆叠布局。本包无配置字段；分页设置由宿主返回。

工作中心声明可选的 `work-center.intake.templates` 列表插槽。独立挂载的模板插件可以保存和载入简报；载入使预览失效，并保留明确选择的执行者和工作区。已记录任务简报可复制到新建表单，不触发执行。

所选运行的诊断须显式读取。报告展示原始证据、精确错误码、来源会话、节点区间及不可用来源。刷新、来源变化和重连使保留报告过期，不自动读取证据。修复按钮打开已有模型、运行时、能力检查或工作流页面。完整重试预览原捕获配置与当前脱敏配置，并提示副作用。确认请求跨页面挂载和选择变化保留。响应丢失时须显式恢复原请求，重连不会自动重发；完整应用重新加载后草稿不保留。

工作中心也声明 `work-center.delivery.artifacts`：可选贡献收到所选执行、已提交评审及禁用状态。[项目产物](../ui-work-artifacts/README.zh.md) 负责登记控件及目录；没有贡献时仍可检查交付。

## Model Experience

间接通过 [dsh-workbench-agent](../../business/workbench-agent/README.zh.md#model-experience) 和 [dsh-work-center](../../business/work-center/README.zh.md#model-experience)，由它们负责任务提示词构造与明确的修改任务执行。渲染、筛选和保存验收不调用模型。

#### KV Cache effect

宿主执行所有者决定新会话提示词。浏览器查看状态不修改已有请求前缀。

## Known Limitations and Deferred Work

- 不提供离线提交、跨宿主目录、团队身份、导出或持久化浏览器草稿。会话等待事项依赖当前连接。文件证据来自检查时刻，而非执行时刻。宿主的证据与历史容量限制仍然适用。
