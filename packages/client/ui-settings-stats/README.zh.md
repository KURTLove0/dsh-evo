# @deepseek-ai/dsh-client-ui-settings-stats

[English](README.md) | 中文

现有配置面板内的只读统计模块。运行范围统计与全机会话总计采用独立口径。页面使用共享赛博主题令牌、带标签的原生日期控件、可见键盘焦点，以及窄屏下可通过键盘聚焦的内部表格滚动区。

## 运行范围

可选工作服务子 fiber 向声明的 `settings.stats.runs` 插槽贡献内容；未装配该服务时，全机会话汇总仍可用。子插槽渲染[工作中心统计](../../business/work-center/README.zh.md#run-statistics)。控件选择包含起止日期的本地日历范围、工作区、执行来源及带来源类型的智能体或工作流，也包含已归档身份。提交时将结束日期解析为下一日本地午夜，并保留浏览器的 IANA 时区。只有显式读取才应用控件变化。分组在执行者、工作区及提交日期间切换，不额外查询。

数量统计只读来源目录，不检查日志。独立的显式操作在宿主上限内读取已记录用量证据。缺失报告及时长样本保持不可用，不视为零；用量带来源覆盖及尝试读取的会话上限。执行成功、验证断言和人工验收是独立事实。日期选择提交范围，总耗时包含排队和人工等待。完整语义及资源限制由提供方定义。

无 React 的 `WorkStatisticsManager` 持有宿主观察、安全选项、独立错误及迟到读取隔离。声明的查看状态在应用内跨页面挂载保留日期和维度控件。来源变化、规范化的连接待处理集合变化、筛选变化及重连只使结果过期，不自动重新读取日志。断连或读取失败保留原已提交筛选对应的报告。应用完整重新加载会丢弃本地查看草稿。

## 全机会话

独立的 `session.list` 读取统计持久化及已开始会话，累加可用的 `tokenUsage` 投影基线，并展示费用占位。汇总包含全部持久化会话，不受日期或运行筛选影响。缺失投影不贡献已观察总和。会话列举没有推送事件，因此在挂载时加载，由用户显式刷新。此汇总失败不隐藏运行范围统计。

## Model Experience

无，因为本模块只读执行和会话观察，不创建模型请求。

#### KV Cache effect

无；本包不组装或发送提供方请求。

## Known Limitations and Deferred Work

- 费用没有权威价格来源，不提供金额估算。已报告 Token 可能缺少部分请求及嵌套委派用量，不代表账单总额。
- 普通会话进入全机会话汇总，不虚构为智能体／工作流运行。当前智能体待处理状态仅属于连接，不代表历史人工等待时长。
- 运行范围读取有容量上限。全机会话总计保留会话列举的独立全时段口径；来源变化标记运行观察过期，不连续轮询日志。
