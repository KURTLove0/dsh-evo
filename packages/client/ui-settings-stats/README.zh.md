# @deepseek-ai/dsh-client-ui-settings-stats

[English](README.md) | 中文

统计设置插件：一个只读设置页，用一次 `session.list` 调用回答"本机存在多少会话、消耗了多少"。行本身统计会话数与已开始对话数；每行的 `tokenUsage` 投影基线——会话统计条逐会话展示的持久四桶供应商账目——在客户端求和为整主机聚合值。页面渲染三张指标卡：会话数、Token 用量（计费输入加输出总量，附分桶明细）、费用。费用卡是显式的无计费源占位：主机不记录价格，聚合值也未按模型分桶，因此不发明数字。

页面从不写、不订阅任何事件：会话列举没有推送事件，页面挂载时加载、只在用户自己的手势时刷新。列举行不携带用量投影的会话（从未上报用量，或投影基线降级）贡献空而非"带警告的零"——缺失是主机的回答，不是错误。导航行注册在 `settings.section` 槽的 shell 认领顶级统计模块行，面板因此读作配置模块的统计功能。

## Model Experience

无——本节渲染只读浏览器视图，没有任何内容进入模型请求。

#### KV Cache effect

无；本包既不组装也不发送供应商请求。

## Known Limitations and Deferred Work

- **费用在计费来源出现前是占位** —— 卡片显示显式的无计费源破折号；计算真实数字需要主机不拥有的价格数据面，且用量聚合未按模型或供应商分桶，因此不提供估算。
- **无时间窗** —— `session.list` 没有日期过滤，每个数字都是全部持久会话的整主机口径；"近 7 天"范围需要先有列举参数。
- **新鲜度以手势为界** —— 页面加载后创建的会话只有在刷新控件或重新进入后出现；没有 session-list 推送事件可收敛。
