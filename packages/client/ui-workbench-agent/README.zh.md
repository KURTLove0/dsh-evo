# dsh-client-ui-workbench-agent

[English](README.md) | 中文

工作台“智能体”页面通过 [dsh-workbench-agent](../../business/workbench-agent/README.zh.md) 管理独立的工作成员，不读取、复制、选择或编辑 Agent 预设。

## 界面

搜索名称、简介和技能，筛选可用、执行中、有排队任务或已归档身份，并按名称或最近修改排序。工作负载概览展示可用身份数、执行中及排队任务数和宿主可用状态。每个身份展示执行中任务数及其并发上限。可以从空白创建身份，编辑名称、头像文字、简介、指令、本地运行时服务、模型覆盖、推理级别、技能、并发上限和最多三个开场提示。草稿在通知刷新后仍保留原版本，其他编辑者保存后会产生冲突，不会覆盖。保存失败保留草稿。关闭已修改的表单时，会询问放弃修改或继续编辑。

选择身份后打开独立详情页，点击“智能体”面包屑返回保留筛选条件的目录。页头展示名称、简介、可用状态、模型选择、运行时和并发，并提供分配工作、编辑、复制及归档操作。概览区分当前工作与最近十条已结束记录；工作、指令、Skills、MCP 和设置各有可通过键盘切换的标签页。侧栏汇总已保存配置与所选能力。

创建和编辑弹窗在同一表单中分组展示身份、指令、Skills、MCP 和运行设置。章节导航滚动到相应字段，所有字段保持挂载，以执行原生校验并统一保存。身份预览、固定标题、可滚动内容以及始终可见的保存和取消操作适应视口大小；窄屏下导航和字段纵向排列。

近三十天统计覆盖当前及之前 29 个本地日历日内创建的保留记录。成功率为完成记录数除以已结束记录数，分母包含失败、取消和中断，排除执行中和排队记录。平均耗时仅采用具有非负开始、结束时间差的已结束记录；无可用成功率或耗时时显示短横线。活动图按本地日期计数保留的提交记录，不代表未保留的历史执行。

技能选择器按所选来源工作区发现允许用户调用的项目和运行时技能，支持搜索和刷新，并保留该工作区未发现的选中项，供用户明确移除。来源工作区只选择发现目录，每个任务仍单独选择执行工作区，也可以显式输入技能名称。MCP 编辑器可添加具名 stdio 或 Streamable HTTP 服务、参数数组、环境变量和请求头。输入框遮蔽变量值，仅在保存时持久化。这些能力同时支持首次创建和后续编辑。

任务文本和工作区选择按身份保留，在同一次应用加载期间，跨页面导航和页面重新挂载仍有效。任务提交成功仅清空对应身份的任务文本，提交被拒绝时保留。点击开场提示仅填入任务框。选择工作区后可提交任务，或描述智能体并请求“AI 生成配置”。AI 结果作为可编辑草稿打开，仍需保存。执行记录按提交时间倒序排列，可按工作类型和执行状态筛选，或搜索任务文本、错误和工作区名称。记录区分任务执行与配置生成，展示工作区和提交、开始、结束时间，提供捕获配置、错误、会话链接、停止和重试操作。捕获的指令、模型选择、技能和并发上限不受后续身份编辑影响。运行时不可用时禁用重试。新提交会清空历史筛选条件，确保提交的记录可见。复制产生独立身份。归档前确认取消未完成任务，历史保留，已归档身份可以恢复。

无 React 的目录管理器持有宿主数据，合并实时通知和重连读取。入口声明的状态保留查看偏好与未保存草稿。插件卸载时撤销插槽、事件监听和目录发布。

运行方式卡片并列展示本地运行时和模型选择。服务与原生默认模型来自“运行时”共用的提供方目录，切换服务清空模型覆盖；不可用或已移除的服务不会静默回退到全局提供方。目录加载、失败、重试及空状态均明确展示。

重试打开确认框，展示原捕获配置与当前脱敏配置、来源运行及已确认版本；提交前明确提示重复外部副作用。关闭保留待确认请求，放弃须显式操作。首次提交前配置改变或缺失会禁用提交。已提交请求可在响应丢失后用同一标识手动恢复，并跨页面挂载保留；重连不自动提交，应用完整重新加载后不保留。

## Model Experience

通过由宿主独立 workbench-agent 服务处理的任务提交与配置设计请求间接影响模型。

#### KV Cache effect

浏览器不组装模型请求，宿主服务持有每个独立任务或配置设计会话的前缀。

## Known Limitations and Deferred Work

- 运行时选择限于当前宿主已注册的本地服务，不提供远程机器执行或多用户设置。
- 可选显式技能名和推理级别以文本编辑；模型从所选本地服务的参考目录选择。
