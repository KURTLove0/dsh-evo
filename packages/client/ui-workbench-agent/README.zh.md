# dsh-client-ui-workbench-agent

[English](README.md) | 中文

工作台“智能体”页面通过 [dsh-workbench-agent](../../business/workbench-agent/README.zh.md) 管理独立的工作成员，不读取、复制、选择或编辑 Agent 预设。

## 界面

搜索名称和简介，筛选可用、执行中或已归档身份。可以从空白创建身份，编辑名称、头像文字、简介、指令、原生运行时、模型、推理级别、技能、并发上限和最多三个开场提示。草稿在通知刷新后仍保留原版本，其他编辑者保存后会产生冲突，不会覆盖。保存失败保留草稿。

创建和编辑弹窗适应视口大小，表单内容可滚动，保存和取消按钮始终可见。窄屏下字段使用单列布局。

点击开场提示仅填入任务框。选择工作区后可提交任务，或描述智能体并请求“AI 生成配置”。AI 结果作为可编辑草稿打开，仍需保存。执行记录页展示真实的排队、执行中、完成、失败、取消、中断状态、捕获版本、错误、会话链接、停止和重试操作。复制产生独立身份。归档前确认取消未完成任务，历史保留，已归档身份可以恢复。

无 React 的目录管理器持有宿主数据，合并实时通知和重连读取。入口声明的状态保留查看偏好与未保存草稿。插件卸载时撤销插槽、事件监听和目录发布。

## Model Experience

通过由宿主独立 workbench-agent 服务处理的任务提交与配置设计请求间接影响模型。

#### KV Cache effect

浏览器不组装模型请求，宿主服务持有每个独立任务或配置设计会话的前缀。

## Known Limitations and Deferred Work

- 内置运行时为当前宿主的 Harness，不展示未支持的外部运行时或多用户设置。
- 技能名和模型路由以文本编辑，执行时依据所选工作区和部署能力解析。
