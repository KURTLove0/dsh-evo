# @deepseek-ai/dsh-client-ui-business-workflow

[English](README.md) | 中文

侧栏打开独立的工作空间业务工作流页面，会话顶部不展示业务工作流模块。“新建工作流”在页面内展开表单，需选择工作空间并填写名称和业务需求，收起后保留未完成的填写内容；目录为空时自动展开。目录支持忽略大小写的名称搜索、工作空间筛选、无匹配时清除筛选，以及最近运行的状态标记。目录直接读取持久化业务 API，不依赖当前会话。历史记录通过会话链接和对话卡片查看。

目录与详情组成分栏视图，根据页面可用宽度切换为上下布局。设计、运行和验证使用分段页签，支持方向键、Home 和 End。收起新建表单后焦点返回入口；操作组根据草稿是否已编辑突出保存或发布，草稿状态与执行成功状态分开展示。页面使用主题变量、可见焦点、减少动态效果及高对比度样式。

流程设计页将可折叠的业务需求放在画布上方，宽屏下将所选节点检查器放在画布旁边。验收用例通过名称、样例输入 JSON 和判定条件控件编辑；编辑器还可编辑业务目标、节点指令、预设、依赖、输入来源和最终输出绑定。节点卡片展示序号、类型和状态，可用鼠标或键盘选择。节点支持拖动、方向键和按钮移动、缩放、适应画布、滚动和自动布局；移动按钮在“节点位置”下展开，视口缩放不改变保存的位置。依赖是连线的唯一来源，修改显示名称或位置不改变节点身份。本地草稿跨页面挂载保留，携带原始修订号，并发保存冲突不能静默覆盖。发布要求草稿已保存且校验通过。AI 编排作为独立候选展示，由用户明确采用。

运行和验证页分开展示执行选择与所选运行详情，包括固定的发布版本流程图、实际输入、完整执行提示、模型与提供方、工具、工作目录、时间、输出、错误和执行会话链接。人工确认和取消直接调用 Remote 命令。验收断言结果独立于执行是否成功。重新运行创建新身份并再次执行全部节点。无效的运行输入 JSON 在切换页签后仍阻止提交；编辑器卸载时释放其校验状态。Host 通知与重新连接通过不依赖 React 的 runtime 对象刷新权威快照。

## 模型体验

只有 AI 编排和 Agent 节点调用模型。编排生成接收业务需求、当前已保存草稿、定义 JSON Schema 和允许的预设，并禁用工具。Agent 节点在独立子会话中接收业务背景与明确绑定的输入。保存、发布、选择记录和人工决策不产生对话回合。

#### KV Cache 影响

独立执行会话不追加到用户对话中，每个新子会话拥有自己的请求前缀和历史。

## 已知限制与延后工作

- 画布复用 SVG 渲染与确定性布局；React Flow 和 Dagre 集成需要安装相应依赖。
- 业务目标、数据字段、约束和来源绑定使用表单控件；样例输入和高级定义使用带标签的 JSON 编辑器。发布前由服务端校验全部字段和引用。
- 目录及选中记录的历史以完整快照读取；大输出分页和增量游标传输尚未提供。
