# @deepseek-ai/dsh-client-ui-work-knowledge

[English](README.md) | 中文

基于生成的 `workKnowledgeGateway` 提供知识目录页面和侧栏入口，沿用赛博工作台 Token 与共享工作空间投影。[Work Knowledge](../../business/work-knowledge/README.zh.md) 负责文件授权、不可变捕获、当前访问检查、字面检索和引用校验。

## 来源管理与引用

选择工作空间并输入项目内相对文件路径。添加即显式启用来源，索引是另一项操作。页面展示授权状态、成功版本、最近完成尝试与失败，不替换较早捕获。启停和索引固定来源修订号；选择来源和刷新元数据不读取文件内容。

字面检索使用最新启用捕获与服务端公布的命中上限。命中保留精确的来源/版本/摘要/行引用；排除来源和当前文件差异分别展示。选择版本与闭区间行范围后显式读取捕获原文，HTML 与代码只作为惰性文本节点。复制引用序列化路径及全部不可变引用字段，不启动任务，也不向已有会话注入材料。

[运行时管理器](../runtime/README.zh.md) 负责元数据、检索、预览、读取世代及一个待确认操作。工作空间、连接、授权命令和元数据刷新会清除已读取内容。重连只刷新元数据，不重复检索、引用读取或命令。已有未确认操作未解决或本地清除前，页面禁用新命令。重试保留登记/索引身份与预期修订；启停重试可能报告修订冲突，需要刷新并检查权威状态。清除本地待确认状态不会撤销服务端数据。

## 生命周期与无障碍

插件生命周期内，输入草稿和待确认操作跨页面重挂载保留。整页重载会丢失本地待确认输入，但 Host 已提交来源元数据与捕获仍可查询。本包不将项目文本或路径保存在浏览器持久存储。页面提供双语、既有明暗配色、带标签且焦点可见的键盘控件，并在窄屏堆叠来源与阅读区域。剪贴板失败时，引用仍可选中并手动复制。

Host 入口不提供行为。页面/导航插槽、语言字典、连接观察和管理器发布归 Client 插件所有，卸载时释放。其他组合可选启用；Web Bundle 默认挂载 Provider、工具和页面。

## 模型体验

无，本插件管理授权并显式读取/复制惰性资料，不注册工具、不提交提示词、不改变会话上下文。单独挂载的知识工具负责日志化模型消费。

#### KV 缓存影响

页面不调用模型，也不改写会话前缀。用户粘贴的引用只参与之后显式提交的提示词。

## 已知限制与待办

- 仅支持单 Host 私有知识来源，完整值限制由服务端负责。不提供递归选择、文档转换、外部知识 Provider、自动后台索引、语义排序、来源删除或共享。当前文件丢失或不可读时，历史内容读取同样被拒绝。整页重载后，对回执可能丢失的操作发起新请求前，需先检查已提交状态。
