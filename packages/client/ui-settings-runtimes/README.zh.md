# @deepseek-ai/dsh-client-ui-settings-runtimes

[English](README.md) | 中文

运行时设置插件：一个只读的设置页，列出当前部署可调用的模型运行时，复用「模型」页已有的两个 wire 域——`llm.providers`（可配置提供方目录，含每条路由的活跃/休眠状态）与 `llm.models`（host 侧模型目录）。一份共享快照按路由 id 连接两者：活跃运行时把其已加载的模型渲染为等宽芯片并附计数说明；该运行时的模型列举失败时渲染目录失败文本；休眠运行时则渲染它在哪里配置（「模型」页），因为没有注册适配器的路由没有可加载的内容。

本页从不写入。运行时配置归「模型」页（`settings.mutate` / `credentials.set`），模型选择归输入框的选择器——本节只报告与指引，从不路由。首次加载后，它订阅转发的 `settings/document-updated` 与 `llm/adapters-updated` owner 事件以及本地 `connection/reset`，因此 settings 促成的路由增减无需轮询即可收敛；未打开的页面从不抓取。行保持目录声明顺序；活跃状态以圆点加状态词呈现（绝不作为提供方健康——休眠路由是配置事实，不是故障）；空目录渲染空部署提示而非错误。

## Model Experience

无；本节渲染只读浏览器视图，不触达任何模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **本页是视图而非管理器**：它从不写入——运行时配置归「模型」页，模型选择归输入框的选择器，因此这里没有可供构建或误用的编辑/删除/新建入口。需要变更的运行时会被指引到它的配置面。
- **活跃状态是目录状态而非健康度**：休眠行表示路由未注册（配置事实），而非任何东西坏了；模型列举失败的活跃路由携带失败文本而非降级状态芯片，因为 host 对每条路由只报告一个目录事实。
