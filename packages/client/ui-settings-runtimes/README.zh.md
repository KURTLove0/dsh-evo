# @deepseek-ai/dsh-client-ui-settings-runtimes

[English](README.md) | 中文

运行时设置插件：一个只读的设置页，列出当前部署可调用的模型运行时，复用「模型」页已有的两个 wire 域——`llm.providers`（可配置提供方目录，含每条路由的活跃/休眠状态）与 `llm.models`（host 侧模型目录）。一份共享快照仅对活跃路由按路由 id 连接两者：每一行都渲染其运行时已加载的模型（等宽芯片附计数说明），该运行时的模型列举失败时渲染目录失败文本。休眠路由不出现——它是以「模型」页为家的配置候选，不是当前部署可调用的运行时。本地 CLI 运行时——适配器以 `localCommand` 声明的那类——仅当 host 在本机找到该可执行文件时才拥有行：未安装的 CLI 在这里不是运行时，直接不出现；而探测到自家 CLI 的适配器会自行激活路由（`llm-claude-cli` 的 codex 驱动模式），因此可用的本地运行时再不需要等待任何 `settings.yaml` 条目。

本页从不写入。API 提供方配置归「模型」页（`settings.mutate` / `credentials.set`），本地运行时的覆盖项归 `settings.yaml`，模型选择归输入框的选择器——本节只报告与指引，从不路由。首次加载后，它订阅转发的 `settings/document-updated` 与 `llm/adapters-updated` owner 事件以及本地 `connection/reset`，因此 settings 促成的路由增减无需轮询即可收敛；未打开的页面从不抓取。行保持目录声明顺序，且每一行按构造即为活跃；空目录渲染空部署提示而非错误。

## Model Experience

无；本节渲染只读浏览器视图，不触达任何模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **本页是视图而非管理器**：它从不写入——API 提供方配置归「模型」页，本地运行时的覆盖项归 `settings.yaml`，模型选择归输入框的选择器，因此这里没有可供构建或误用的编辑/删除/新建入口。需要变更的运行时会被指引到它的配置面。
- **只列出活跃路由**——休眠路由是「模型」页的配置候选，不是这里的运行时，因此也不存在可供两面解读的未启用行；模型列举失败的活跃路由携带失败文本而非降级状态芯片，因为 host 对每条路由只报告一个目录事实。
