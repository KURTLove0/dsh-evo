# @deepseek-ai/dsh-client-ui-work-triggers

[English](README.md) | 中文

[dsh-work-triggers](../../business/work-triggers/README.zh.md) 的工作触发目录及可选 `work-center.delivery.triggers` 准备控件。使用现有赛博主题令牌、双语标签、可见焦点及窄屏堆叠布局。

## 界面

从工作中心的原执行准备目标，检查固定内容后，显式将其用于新规则。智能体使用原任务内容及当前执行者版本；正式工作流使用原发布版本和输入。时间输入必须是有效 ISO 日期并包含明确 UTC 偏移。固定间隔使用毫秒，不按日历重复。保存为暂停及创建并启用是独立操作。

目录按名称、工作空间及启用状态筛选。详情分开展示规则消耗、原生接纳、终态观察及保留通知。原执行链接打开原生会话记录。暂停只影响后续交接，不取消已有任务。恢复使用原触发身份及尝试次数；通知已读与人工交付验收相互独立。

不依赖 React 的管理器拥有读取代次及修改生命周期。出错时保留上次观察。连接变化使读取过期；重连不会重试命令。声明的视图存储在页面重新挂载时保留草稿和精确的未确认命令。恢复创建复用身份及内容，然后读取当前状态。未确认控制需要权威读取并显式清除本地记录后，才能作出下一决定。清除不撤销主机工作。插件卸载移除订阅、插槽及读取发布。

## 模型体验

间接影响，经过 [dsh-work-triggers](../../business/work-triggers/README.zh.md#model-experience)，由原生执行所有者记录显式授权的任务内容。

#### KV Cache 影响

呈现及管理不发起模型请求。原生执行所有者决定已接纳任务的提示词及前缀。

## 已知限制与延后工作

- 主机必须保持运行。不提供浏览器持久草稿、离线写入、目标编辑、删除、外部通知或操作系统唤醒。完整刷新会丢弃本地未确认输入；已提交的主机记录仍可读取。
